# 🌍 Globaly | Business Consulting Website

A modern and fully responsive business consulting website built with HTML5, CSS3, and JavaScript. Globaly provides an elegant corporate web presence with interactive UI components, smooth animations, testimonials carousel, animated statistics, and a professional business-oriented design.

## ✨ Features

### 🎯 User Interface

* Modern and professional business consulting design
* Fully responsive layout for all screen sizes
* Sticky navigation bar
* Smooth scrolling experience
* Custom loading screen animation
* Animated section titles

### 🔍 Navigation & Search

* Interactive navigation menu
* Mobile hamburger menu
* Search functionality for quick section navigation
* Active link highlighting

### 🎨 Interactive Components

* Hero section with automatic background slider
* Manual slider controls
* Animated statistics counter
* Client testimonials carousel
* Hover effects and transitions
* Scroll-to-top button

### 📱 Responsive Design

* Mobile-first responsive layout
* Optimized for Desktop, Laptop, Tablet, and Mobile devices
